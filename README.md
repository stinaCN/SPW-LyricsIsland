# 灵动岛歌词

为 **椒盐音乐（Salt Player for Windows）** 提供的灵动岛歌词插件。

把歌词、封面和播放状态显示成屏幕顶部的一条灵动岛浮窗。
悬停展开后可看到逐字歌词、翻译、进度条，并可直接控制播放。

## 安装

1. 到 [Releases](../../releases) 下载 `plugin-com.liufe.spw.winisland-x.y.z.spmod`
2. 打开椒盐音乐，进入 **设置 → 创意工坊**，导入刚下载的 `.spmod`
3. 在模组管理中启用「灵动岛歌词」，并授予**曲库读取**权限

需要 **椒盐音乐 1.19.0 及以上**。

## 使用

- 收起时显示歌名与当前歌词，悬停展开
- 展开后底部有 **上一曲 / 播放暂停 / 下一曲**，点击会作用回椒盐音乐
- 拖拽进度条可跳转播放位置
- 外观、停靠位置、缩放等设置可在模组设置面板自由调整。

## 引用

本插件基于 [WinIsland](https://github.com/Eatgrapes/WinIsland) 进行构建。
